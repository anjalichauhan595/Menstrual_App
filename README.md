# Menstrual Cycle Prediction App

## Why This Project

Menstrual cycle irregularities affect an estimated **14% to 25% of women of childbearing age** (Whitaker, L., & Critchley, H. O. D., 2016, *Abnormal uterine bleeding*. *Best Practice & Research Clinical Obstetrics & Gynaecology*, 34, 54–65. [ScienceDirect](http://www.sciencedirect.com/science/article/pii/S1521693415002266)), yet most period tracking apps assume regular cycles. This project aims to **develop a personalized cycle prediction app** that accounts for individual variability, helping users better understand their phases and track symptoms accurately.

Additionally, this project serves as a **personal learning opportunity**, allowing me to refresh and strengthen my coding skills prior to beginning graduate studies in **bioinformatics**.
